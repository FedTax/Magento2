# TaxCloud for Magento 2

> Sales Tax at the Speed of Commerce

!!! warning "Work in progress"
    This documentation site is being written. Most pages are still
    placeholders — until they are filled in, the
    [README](https://github.com/FedTax/Magento2#readme) remains the reference
    documentation for the extension.

This site documents the **TaxCloud extension for Magento 2 / Adobe Commerce**:
installation, configuration, and how each feature behaves. It is written for
store owners and administrators.

## Sections

- **Getting started** — what the extension does, TaxCloud account setup,
  installing, and the shortest path to charging correct tax.
- **Configuration** — [every admin setting explained](settings.md), choosing
  between the V1 SOAP and V3 REST APIs, and multi-store setups.
- **Taxability (TICs)** — what a Taxability Information Code is, assigning them
  to products and categories, and how shipping is taxed.
- **Exemption certificates** — enabling exemptions, managing certificates,
  what the customer sees, and how an order becomes exempt.
- **Orders and tax lifecycle** — what happens at checkout, capture, refunds,
  cancellations, and filing.
- **Troubleshooting** — logs, caching, common problems, and testing your setup.
- **Development** — extension points and the project's own test suites.

## Contributing to the docs

Pages are plain Markdown files in the [`docs/` folder of the
repository](https://github.com/FedTax/Magento2/tree/main/docs). Edit a page
(or use the pencil icon in the header), open a pull request, and the site
rebuilds automatically when it merges.

Before writing, read [Writing documentation](writing-documentation.md) — it
defines who these pages are for and how to write for them.
